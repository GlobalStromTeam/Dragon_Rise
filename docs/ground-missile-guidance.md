# 地面导弹转向与待发射锁

2026-11-16：在本包实现导弹转向限制，并在上一发导弹等待出筒期间锁住同一平台的后续导弹触发。

## 作用范围与默认值

作用于上一轮增加发射延迟的 27 个配置（25 台现代地面载具、短号和红箭 8 两种架设武器），共 29 个导弹选项。发射来源通过 Superb Warfare `GunItem.shootBullet(ShootParameters)` 中的实际 `ammoSupplier` 确认，在弹体加入世界前记录，覆盖玩家、AI 和延迟发射。

| 弹体类型 | 默认三维转向上限 |
| --- | ---: |
| WireGuideMissileEntity 及本包 TOW 顶攻子类 | 2°/tick |
| Ru9m336MissileEntity 地面防空导弹 | 4°/tick |
| JavelinMissileEntity 普通/爬升阶段 | 3°/tick |
| JavelinMissileEntity 顶攻末段 | 4°/tick |

顶攻末段沿用前置判定：顶攻模式，且与目标的水平距离小于 30 格。普通直射模式不会取得顶攻末段上限。线导、防空导弹保留前置初段转向能力逐渐增加的过程。

数值表示游戏中的角速度，不是真实物理过载 G。限制采用三维向量夹角，水平与俯仰同时转向也共享同一角度预算。每个制导 tick 分别约束弹头朝向与实际速度方向，保留前置原有的转向惯性、目标解算和计算后的速度大小，不另外改变推力、阻力或弹速。

来源标记保存在弹体 ForgeData，生成包与远距 BVR 同步也携带该标记，存档重载、射手下车之后仍保留。没有标记的导弹不进入限制器，因此前置原版车辆、其它附属模组以及本包飞机、直升机等不受本轮限制。

当前来源配置：625e、9m133、akm、bmd4m、bmp3、bmpt72、btr90、cv90、flarakpz1、hj8、humveetow、l1a2、m1128、m3a3、tunguska、vt4a1、vt4b、zbd04a、zbd05、zbl08、zlt11、zsu234、ztd05、ztq15、ztz99a、ztz99ah、ztz99bh。未来新增型号需补入 `GroundMissileGuidance.LAUNCHERS`。

## 服务端配置

Forge 自动生成并向客户端同步世界配置：`<世界目录>/serverconfig/dragonrise_reforge-missiles-server.toml`。独立服务器通常为 `world/serverconfig/`，单机通常为 `saves/<世界>/serverconfig/`。

```toml
[turn_limits]
wire_guided = 2.0
anti_air = 4.0
anti_tank = 3.0
top_attack_terminal = 4.0
```

允许范围 0～180°/tick。修改后按 Forge 世界配置加载机制生效；建议退出并重新加载世界再做同条件比较。

## 发射等待锁

- 服务端三个 `VehicleEntity.vehicleShoot` 重载都在排队前校验。锁按整台载具/架设武器生效，不能通过更换导弹武器或座位再排一发；其它平台和非导弹武器独立。
- 第一发被接受后进入待发射状态。弹体成功加入世界后解锁；已有武器射速、装填和发射架条件仍然生效。
- 如果原有发射流程取消或因弹药等原因没有产生弹体，在发射延迟结束后再经过 1 tick 兜底解锁。任务令牌避免上一发的兜底回调误解锁下一发。
- 短号、红箭 8 的实体覆写即使在父类拒绝发射后继续返回，也不能重复排入尾焰、抛筒等效果。
- 客户端在发送请求和播放触发声之前预测加锁。服务器同步接受/完成状态后，已确认的锁仅由服务器释放，客户端计时变快不会自行解锁。尚未被服务器接受的预测有恢复超时，以兼容原有车速/发射架门槛拒绝的请求；切换世界清空预测状态。

保留上一轮 30 tick 发射延迟及全部声音资源、声音引用；本轮不修改载具或武器 JSON。

## 验证

- 50,000 组真实 Minecraft Vec3 数学测试：三维角度上限、候选速度大小、斜向转向、反向目标、零速、零角度上限与 ±180° 跨界。
- 服务端锁测试：重复请求、独立平台、效果只排一次、失败恢复、旧超时不能释放新发射。
- 客户端状态测试：预测拦截、服务器确认后不随本地时间解锁、完成后恢复、旧消息不能释放新确认状态、切换世界清理；同步包编解码往返。
- 隔离 Forge GameTest 服务端的两个测试通过：实际防空弹 `tick` 的转向限制与速度对照、普通生成数据/存档/BVR 标记、官方/飞机排除、顶攻阶段区分，以及真实架设武器三个开火入口的重复排队拦截、延迟扣弹和解锁。
- JDK17 离线构建、生产 refmap 和最终 JAR 检查通过；未进行客户端目视或对战命中率测试，当前数值作为首轮平衡值。

测试源码、隔离测试世界和审计报告位于忽略目录 `build/ground_missile_guidance_20261116/`，不进入发布 JAR。
