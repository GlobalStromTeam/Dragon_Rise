# 俄军作战服移动音效试验

目标物品：`dragonrise_reforge:russian_soldier_chest`（俄军士兵作战服），只检查胸甲槽。

普通移动使用 Squad `Audio/Character/Gear/GearSoldierWalk`；疾跑使用 `Gear/GearSoldierSprint/New`，叠加0.18倍的 `Clothing/US_Soldier/Run` 衣服摩擦。两类各随机选择3条，固定种子2026111601。成品6条，单声道、44.1kHz、Vorbis q8；组内最大100ms RMS试验目标为行走−28dBFS、疾跑−25dBFS。蹲行复用行走声，播放倍率0.55、步距和触发间隔放慢。

`UniformMovementSoundHandler`仅在客户端运行，通过原有装备、位置与疾跑状态同步观察本人和附近玩家，无额外网络包。本人相机在自身时使用相对声音，其他玩家使用跟随实体的方向音源，可闻距离8格，归入玩家声音类别。

`UniformMovementCadence`按实际水平位移累计步距，按键顶墙不触发。短暂不位移保留4 tick宽限以兼容远端位置更新；新片段只在本 tick确有位移时开始。触发频率为最初版本的1.5倍，即上一版3倍频率的一半：原先的步距、最短间隔以及片段长度限制统一使用1.5倍速参考时钟，保留小数 tick余量。同一状态的完整片段允许叠加，不再等待上一段结束，也不因新片段开始而截断旧片段；切换状态时交叉淡出。6条OGG内容、长度、音调和单条音量保持不变。片段变体不连续重复。

静止、脱下胸甲、乘车、游泳、飞行、匍匐及旁观状态停止；死亡、卸载实体、离开世界清理声音。停步和脱装淡出3 tick，远端位置更新宽限最长4 tick。单 tick水平位移超过1.5格视为传送/位置跳变，不作为步行触发。

本试验不替换原版脚步声，不改变护甲属性、模型、动画或武器配置。响度是离线指标，尚未游戏内试听。

音频来源、哈希、测量和构建记录：`build/russian_uniform_movement_20261116/`。行为测试以轻量Minecraft/Forge替身运行实际客户端类，覆盖静止、走跑切换、蹲行、脱装、死亡、传送、排除状态、远端位置更新、音源跟随、距离和世界切换；不等同于真实联机试听。

三倍频率回归记录：`build/russian_uniform_movement_frequency_20261116/verification.json`。以旧提交`a608b5e9`为基线，在相同2400 tick连续移动中，行走触发172→515次、疾跑275→830次、蹲行172→514次；客户端tick取整和随机片段长度使计数略有浮动。持续移动时确认已有片段不淡出、不提前终止、音调为1，六条OGG逐字节与旧提交一致。

后续按试听反馈将上述频率减半，当前倍率1.5。回归记录：`build/russian_uniform_movement_half_frequency_20261116/verification.json`，相同2400 tick中行走515→258次、疾跑830→415次、蹲行514→257次，六条OGG逐字节保持一致。
