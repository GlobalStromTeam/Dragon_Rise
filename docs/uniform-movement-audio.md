# 俄军作战服移动音效试验

目标物品：`dragonrise_reforge:russian_soldier_chest`（俄军士兵作战服），只检查胸甲槽。

普通移动使用 Squad `Audio/Character/Gear/GearSoldierWalk`；疾跑使用 `Gear/GearSoldierSprint/New`，叠加0.18倍的 `Clothing/US_Soldier/Run` 衣服摩擦。两类各6条，合计12条成品，单声道、44.1kHz、Vorbis q8。原有每类3条保持原样，种子2026111601；追加每类3条使用种子2026111602，从未使用过的同系列录音中抽取。组内最大100ms RMS试验目标为行走−28dBFS、疾跑−25dBFS；当前成品实测分别约−27.975、−25.006dBFS。蹲行复用全部6条行走声，音量倍率0.55。

`UniformMovementSoundHandler`仅在客户端运行，通过原有装备、位置与疾跑状态同步观察本人和附近玩家，无额外网络包。本人相机在自身时使用相对声音，其他玩家使用跟随实体的方向音源，可闻距离8格，归入玩家声音类别。

`UniformMovementCadence`按实际水平位移累计步距，按键顶墙不触发。短暂不位移保留4 tick宽限以兼容远端位置更新；新片段只在本 tick确有位移时开始。起步立即播放一声装具响；随后行走和疾跑采用原版平地步频：累计水平位移×0.6，超过下一整数时触发，平均约每1.67格一步。走跑切换保留步相，速度改变会自然改变时间间隔，随机片段的长短不再控制行走与疾跑频率。蹲行保留此前减半后的0.75倍速参考时钟，按步距和片段长度控制较慢节奏。同一状态的完整片段允许叠加，也不因新片段开始而截断旧片段；切换状态时交叉淡出。所有片段保留完整长度与尾音，音调为1。片段变体不连续重复。

静止、脱下胸甲、乘车、游泳、飞行、匍匐及旁观状态停止；死亡、卸载实体、离开世界清理声音。停步和脱装淡出3 tick，远端位置更新宽限最长4 tick。单 tick水平位移超过1.5格视为传送/位置跳变，不作为步行触发。

本试验不替换原版脚步声，不改变护甲属性、模型、动画或武器配置。响度是离线指标，尚未游戏内试听。

音频来源、哈希、测量和构建记录：`build/russian_uniform_movement_20261116/`。行为测试以轻量Minecraft/Forge替身运行实际客户端类，覆盖静止、走跑切换、蹲行、脱装、死亡、传送、排除状态、远端位置更新、音源跟随、距离和世界切换；不等同于真实联机试听。

三倍频率回归记录：`build/russian_uniform_movement_frequency_20261116/verification.json`。以旧提交`a608b5e9`为基线，在相同2400 tick连续移动中，行走触发172→515次、疾跑275→830次、蹲行172→514次；客户端tick取整和随机片段长度使计数略有浮动。持续移动时确认已有片段不淡出、不提前终止、音调为1，六条OGG逐字节与旧提交一致。

上一轮按试听反馈将上述频率减半，当时三种姿态倍率均为1.5。回归记录：`build/russian_uniform_movement_half_frequency_20261116/verification.json`，相同2400 tick中行走515→258次、疾跑830→415次、蹲行514→257次，六条OGG逐字节保持一致。

六变体及蹲行再次减半的制作和回归记录：`build/russian_uniform_movement_six_20261116/`。追加行走源编号09、15、08，疾跑源编号27、16、23，混入的衣服摩擦源编号12、05、11；完整路径、源哈希、不可变混音和尾音测量在该目录的`selection.json`、`production.json`中。固定相同片段时长与位移、模拟2400 tick，对比提交`19a125f9`，行走与疾跑节奏计数不变，蹲行257→129次；实际播放模拟确认三种姿态均可选到6个不同变体，原有6条OGG逐字节不变。构建和资源校验通过，未游戏内试听。

行走和疾跑对齐原版步频的记录：`build/russian_uniform_movement_vanilla_steps_20261116/`。参照本项目Forge 47.4.0映射源码中的`Entity.move()`和`nextStep()`，平地距离系数为0.6、下一阈值为`(int)moveDist + 1`。24000 tick回归覆盖行走、疾跑、速度变化、走跑切换及任意音频长度，起步后的触发均与原版距离阈值吻合，旧版本无法通过该回归。相同2400 tick实际播放模拟中，行走253→317次、疾跑413→404次、蹲行保持127次。12条OGG逐字节保持一致；未实机试听。
