# 武器站骨骼绑定

> 载具的"副武器站 / 车顶机枪"怎么让模型跟着视角转，一直是本模组最容易写错的地方。
> 这篇文档记录**三种可用写法**、SBW 的硬编码约束、以及一个能自动查出引用的脚本。
> 新加武器站、或者发现"枪能开火但模型不转"时先读这里。

配套校验：`node tools/check_weapon_station.mjs <项目根目录>`

---

## 一、三种写法（按推荐程度排序）

### A. 银手5 式：绑定骨骼 `BoundBonesYaw` / `BoundBonesPitch`

**用例**：`silverhand_mk_iv`（MachineGun，源自 2026-09-14 提交 `400bbaa3`）、`cav`（PassengerMachineGun，MK19）

**模型**（骨骼名必须是 `<任意前缀>Yaw` / `<任意前缀>Pitch`）：

```
body
└ move_hullGunYaw       0 cubes     ← 偏航骨，可以没有几何
   └ move_hullGunPitch  27 cubes    ← 俯仰骨，挂枪体几何
```

**数据**：

```json
"MachineGun": {
  "BoundBonesYaw":   ["move_hullGunYaw"],
  "BoundBonesPitch": ["move_hullGunPitch"],
  "ShootPos": {
    "Transform": "Vehicle",
    "Positions": [[-0.587, 2.406, 5.5]],
    "DefaultTransform": "Default",
    "DefaultBarrelDirection": [0, 0, 1],
    "Directions": ["Passenger"]
  }
}
```

要点：

- **骨骼名必须以 `Yaw` / `Pitch` 结尾**。写成 `move_mk19a` / `move_mk19b` 不会转 —— SBW 靠后缀识别旋转轴，`BoundBones*` 里的字符串只是"点名"。
- `Positions` 是**车体空间**坐标（不是骨内偏移），换算规律见第五节。
- `Transform` 保持 `Vehicle`，`Directions` 用 `Passenger`（跟随座位玩家视角）。

### B. 标准武器站：`WeaponStation` / `WeaponStationBarrel`

**用例**：`2s25m`、`amx56`、`btr90`(GrenadeLauncher)、`chonmaho5`

**模型**（这三根骨的名字**写死在 SBW 里**，不能改）：

```
turret
└ passengerWeaponStation        0~2 cubes
   └ passengerWeaponStationYaw    偏航，挂几何
      └ passengerWeaponStationPitch  俯仰，挂几何
```

**数据**：

```json
"PassengerMachineGun": {
  "ShootPos": {
    "Transform":  "WeaponStationBarrel",
    "Directions": ["WeaponStationBarrel"],
    "Positions":  [[0.06789, 0.026982, 0.598499]]
  }
}
```

根级还要有（缺了模型不跟随，枪口位置也会错）：

```json
"PassengerWeaponStationPos":       [-0.694, -0.007, 1.334],
"PassengerWeaponStationBarrelPos": [-0.112, 0.309, -0.19],
"PassengerWeaponStationTurnSpeed": [10, 10],
"PassengerWeaponStationPitchRange": [-9, 60]
```

要点：`Positions` 这里是**相对俯仰骨**的偏移（不是车体空间）。

### C. 车体固定：只有方向跟随视角，模型不转

```json
"ShootPos": {
  "Transform": "Vehicle",
  "Positions": [[-0.856, 2.366, 1.116]],
  "Directions": ["Passenger"]
}
```

**用例**：AC-130H 的各门炮、CAV 的 M2HB（车顶机枪）、大部分老车的同轴/舱口机枪。
开火方向跟视角走，但模型不摆动 —— 要模型也动，用 A 或 B。

## 二、SBW 的硬编码约束（为什么不能随便改名）

从 SBW jar（`superb-warfare-1218165-*`）里反查到的字面量：

| 类 | 硬编码的骨骼名 |
|---|---|
| `VehicleModel` / `GeoVehicleRenderer` / `TurretWreckRenderer` | `passengerWeaponStation`、`passengerWeaponStationYaw`、`passengerWeaponStationPitch` |
| `VehicleModelReloadListener` | 同上三根 |
| `VectorTool` | `passengerWeaponStationYawRot`、`passengerWeaponStationPitchRot` |
| `VehicleEntity` | `WeaponStation`、`WeaponStationBarrel`（transform 关键字） |
| `DefaultGunData` | `BoundBones` / `BoundBonesYaw` / `BoundBonesPitch` 三个数据字段 |

结论：

1. **A 方案**的骨骼名可以自定义，但**必须带 `Yaw` / `Pitch` 后缀**。
2. **B 方案**的三根骨名一个字都不能改。
3. `BoundBones*` 只对 A 方案生效；B 方案写了也没用（不会报错，只是静默忽略）。

## 三、坐标换算（模型 → 数据）

模型是 Bedrock 格式，16 单位 = 1 格，且 **Z 轴方向相反**：

```
数据坐标 = ( pivot.x / 16 , pivot.y / 16 , -pivot.z / 16 )
```

例：CAV 的 `move_mk19b`（俯仰骨）pivot `[-12.9388, 38.1209, -8.971]`
→ `(-0.8087, 2.3826, 0.5607)`

- **A / C 方案**：`Positions` 填枪口的**车体空间**坐标（直接对模型量）。
- **B 方案**：`Positions` 填 `枪口 − 俯仰骨` 的差值。

## 四、新增一个武器站的完整步骤

1. **模型**：在 Blender/Blockbench 里拆两根骨 —— `<前缀>Yaw`（偏航，可无几何）、`<前缀>Pitch`（俯仰，挂枪体几何），Pitch 必须是 Yaw 的子骨。
2. **数据**：加武器块，写 `BoundBonesYaw` / `BoundBonesPitch` + `ShootPos`（A 方案模板见第一节）。
3. **座位**：把武器名加进对应座位的 `Weapons` 数组，给 `MinYaw` / `MaxYaw` / `MinPitch` / `MaxPitch`。
   舱口位原本是 `BanHand: true` 也没关系 —— 仓库里已有 13 处 `BanHand` 座位带武器的先例。
4. **校验**：`node tools/check_weapon_station.mjs E:\Dragon_Rise\Dragon_Rise_1201`，错误必须为 0。
5. **进游戏**：切到该座位，左右看 —— 模型应当跟着摆；打一发确认枪口位置。

## 五、排错对照表

| 现象 | 原因 |
|---|---|
| 能开火，模型完全不动 | 骨骼名没带 `Yaw`/`Pitch` 后缀；或用了 B 方案但模型缺 `passengerWeaponStation*` 骨；或 `BoundBones*` 拼错 |
| 偏航转了，俯仰不转 | 只有 Yaw 骨，Pitch 骨缺失或没挂在 Yaw 下 |
| 模型转了但子弹从车体里出来 | `Positions` 用了骨内偏移，A 方案要填车体空间坐标 |
| 子弹方向对、位置偏移 | 同上，或 `Positions` 的 Z 忘了取反 |
| 模型跟着炮塔转而不是跟视角 | `Transform` 写成了 `Turret` |
| 改了模型骨骼名之后以前好好的枪不转了 | B 方案改到了硬编码骨名，改回 `passengerWeaponStation*` |

## 六、当前基线（2026-11-21）

`node tools/check_weapon_station.mjs` 在 1.20.1 工作树的输出：

```
扫描 163 台载具、442 门武器
错误 3 处，提示 62 处
```

btr90 / Missile    "MissileRack"   模型里实际叫 move_missileRack
m3a3  / Missile    "Tow"           模型里实际叫 tow（小写）

表现为"枪能开火、模型不跟随"。属历史模型遗留，逐个补骨即可，不影响加载。
